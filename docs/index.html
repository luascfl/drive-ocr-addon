OCR for Drive

A Google Drive add-on that makes scanned PDFs searchable. Select a PDF in Drive and click "Start OCR". Within minutes the file is replaced with a version that has selectable, searchable text. Sideways pages are straightened, OCR runs on each intact spread, and double-page scans are then split down the middle with their text layer. The original is kept as an earlier version, and a "Revert OCR" button restores it exactly.

What it does

  • Recognizes text with Tesseract. The add-on currently requests Portuguese and English; the server also has Arabic and Hebrew installed, but they are not selectable in the add-on yet.
  • Keeps the PDF's original images and adds only an invisible text layer, so the new file is about 1% larger than the original.
  • Works only on the files you grant, one at a time. If you have not granted a file yet, Start OCR asks for permission and then starts by itself.
  • "Flatten and re-OCR" saves a separate copy named <name> (flatten).pdf, so you can compare an OCR that already existed with ours.
  • PDFs that already have text on every page are refused, and nothing is changed.

Current limits

  • This project is in a testing phase: it has not been verified by Google yet, so Google shows an "unverified app" warning.
  • Each user can run at most 2 jobs at once and 30 per day. The server is small: a 51-page PDF takes about 13 minutes.
  • PDFs up to 50 MB and 60 pages.

Privacy

The content of your documents is not stored. Read the privacy policy.

Support and source

Questions and problems: open an issue in the project's GitHub repository. The server code and its tests are public in that repository.
